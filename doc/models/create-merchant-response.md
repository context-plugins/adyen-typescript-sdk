
# Create Merchant Response

## Structure

`CreateMerchantResponse`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `businessLineId` | `string \| undefined` | Optional | The unique identifier of the [business line](https://docs.adyen.com/api-explorer/#/legalentity/latest/post/businessLines). |
| `companyId` | `string \| undefined` | Optional | The unique identifier of the company account. |
| `description` | `string \| undefined` | Optional | Your description for the merchant account, maximum 300 characters.<br><br>**Constraints**: *Maximum Length*: `300` |
| `id` | `string \| undefined` | Optional | The unique identifier of the merchant account. If Adyen set up a template for the `reference`, then the `id` will have the same value as the `reference` that you sent in the request. Otherwise, the value is generated by Adyen. |
| `legalEntityId` | `string \| undefined` | Optional | The unique identifier of the [legal entity](https://docs.adyen.com/api-explorer/#/legalentity/latest/post/legalEntities). |
| `pricingPlan` | `string \| undefined` | Optional | Partner pricing plan for the merchant, applicable for merchants under AfP managed company accounts. |
| `reference` | `string \| undefined` | Optional | Your reference for the merchant account. |
