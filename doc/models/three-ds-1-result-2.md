
# Three DS 1 Result 2

The result of the 3D Secure authentication.

## Structure

`ThreeDS1Result2`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `cavv` | `string \| undefined` | Optional | The cardholder authentication value (base64 encoded). |
| `cavvAlgorithm` | `string \| undefined` | Optional | The CAVV algorithm used. |
| `eci` | `string \| undefined` | Optional | 3D Secure Electronic Commerce Indicator (ECI). |
| `threeDAuthenticatedResponse` | `string \| undefined` | Optional | The authentication response from the ACS. |
| `threeDOfferedResponse` | `string \| undefined` | Optional | Whether 3D Secure was offered or not. |
| `xid` | `string \| undefined` | Optional | A unique transaction identifier generated by the MPI on behalf of the merchant to identify the 3D Secure transaction, in `Base64` encoding. |

## Example

```ts
import { ThreeDS1Result2 } from 'adyen';

const threeDS1Result2: ThreeDS1Result2 = {
  cavv: 'cavv8',
  cavvAlgorithm: 'cavvAlgorithm2',
  eci: 'eci2',
  threeDAuthenticatedResponse: 'threeDAuthenticatedResponse4',
  threeDOfferedResponse: 'threeDOfferedResponse8',
};
```
