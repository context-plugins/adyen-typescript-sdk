
# Delivery Timeframe

The estimated delivery time for the shopper to receive the goods.
Allowed values:

* `electronicDelivery`
* `sameDayShipping`
* `overnightShipping`
* `twoOrMoreDaysShipping`

## Enumeration

`DeliveryTimeframe`

## Fields

|  --- |
| `ElectronicDelivery` |
| `SameDayShipping` |
| `OvernightShipping` |
| `TwoOrMoreDaysShipping` |

import { DeliveryTimeframe } from 'adyenlib';

const deliveryTimeframe = DeliveryTimeframe.ElectronicDelivery;
