
# ACH Account Identifier 1

Identifiers relevant for Automated Clearing House (ACH) payments, primarily used in the United States.

## Structure

`ACHAccountIdentifier1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `accountLastDigits` | `string \| undefined` | Optional | The last digits of the account number. If the accountNumber is tokenized, this field contains the last digits of the non-tokenized account number. This helps users verify the account without seeing the full number. |
| `accountNumber` | `string` | Required | The account number of the bank account. |
| `isTokenized` | `boolean \| undefined` | Optional | Indicates whether the account number is tokenized. A tokenized account number is a unique ID generated by a bank to protect the user's actual account number. |
| `routingNumber` | `string` | Required | The [routing number](https://en.wikipedia.org/wiki/ABA_routing_transit_number), without separators or whitespace. |

## Example

```ts
import { ACHAccountIdentifier1 } from 'adyen';

const aCHAccountIdentifier1: ACHAccountIdentifier1 = {
  accountNumber: 'accountNumber6',
  routingNumber: 'routingNumber0',
  accountLastDigits: 'accountLastDigits4',
  isTokenized: false,
};
```
