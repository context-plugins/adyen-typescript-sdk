
# Donation Campaign Nonprofit Cause 2

The nonprofit cause that the campaign supports.

*This model accepts additional fields of type unknown.*

## Structure

`DonationCampaignNonprofitCause2`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `bannerUrl` | `string \| undefined` | Optional | The URL to the banner showing the cause that the nonprofit organization supports. |
| `causeId` | `string \| undefined` | Optional | The unique identifier of the nonprofit cause. This value is generated by Adyen. |
| `description` | `string \| undefined` | Optional | The description of the cause that the nonprofit supports. |
| `globalWebsiteUrl` | `string \| undefined` | Optional | The URL to the website of the nonprofit organization. |
| `goals` | `string[] \| undefined` | Optional | The United Nations Sustainable Development Goals (UN SDGs) supported by the nonprofit organization, specified in the format `unsdg_<number>`, where the number is the number of the UN SDG. For example, **unsdg_1**. |
| `logoUrl` | `string \| undefined` | Optional | The URL to the logo of the nonprofit organization. |
| `nonprofitName` | `string \| undefined` | Optional | The name of the nonprofit organization. |
| `termsAndConditionsUrl` | `string \| undefined` | Optional | The URL to the terms and conditions of the nonprofit organization. |
| `additionalProperties` | `Record<string, unknown>` | Optional | - |
