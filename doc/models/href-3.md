
# Href 3

A short-lived URL that redirects the user to the iDEAL profile management page.

## Structure

`Href3`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `href` | `string` | Required | The full URL for the redirection. |

## Example

```ts
import { Href3 } from 'adyen';

const href3: Href3 = {
  href: 'https://someUrl',
};
```
