
# Links Element 3

Generates a new API key. When you generate a new one, the existing key remains valid for 24 hours.

## Structure

`LinksElement3`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `href` | `string \| undefined` | Optional | - |

## Example

```ts
import { LinksElement3 } from 'adyen';

const linksElement3: LinksElement3 = {
  href: 'href8',
};
```
