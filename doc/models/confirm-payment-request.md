
# Confirm Payment Request

## Structure

`ConfirmPaymentRequest`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `balanceAccountId` | `string` | Required | The balance account ID of the account where the funds should be subtracted.<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `100` |
| `token` | `string` | Required | The payment token is an identifier for the payment. It is generated by Adyen on the response of the payment details.<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `1000` |

## Example

```ts
import { ConfirmPaymentRequest } from 'adyen';

const confirmPaymentRequest: ConfirmPaymentRequest = {
  balanceAccountId: 'BA00000000000000000000000',
  token: 'ewoJIlNvbWVUb2tlbiIgOiAiU29tZUluZm8iCn0=',
};
```
