
# Fraud Result 2

The fraud result properties of the payment.

## Structure

`FraudResult2`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `accountScore` | `number` | Required | The total fraud score generated by the risk checks. |
| `results` | [`FraudCheckResultWrapper[] \| undefined`](../../doc/models/fraud-check-result-wrapper.md) | Optional | The result of the individual risk checks. |

## Example

```ts
import { FraudResult2 } from 'adyen';

const fraudResult2: FraudResult2 = {
  accountScore: 62,
  results: [
    {
      fraudCheckResult: {
        accountScore: 114,
        checkId: 2,
        name: 'name0',
      },
    }
  ],
};
```
