
# Donation Campaign 1

## Structure

`DonationCampaign1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `accountHolderIds` | `string[] \| undefined` | Optional | The unique identifiers of the account holders associated with the donation campaign. |
| `activatedAt` | `string \| undefined` | Optional, Read-only | The date and time when the campaign started, in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format. For example, 2026-06-18T10:28:59.820+00:00 |
| `endedAt` | `string \| undefined` | Optional, Read-only | The date and time when the campaign stopped, in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format.  For example, 2026-06-18T10:28:59.820+00:00. |
| `id` | `string` | Required, Read-only | The unique identifier of the donation campaign. This value is generated by Adyen. |
| `inPerson` | [`InPersonDonationSettingsResponse2 \| undefined`](../../doc/models/in-person-donation-settings-response-2.md) | Optional | The settings for in-person donations collected as part of the campaign. |
| `name` | `string` | Required | The name of the donation campaign. |
| `nonprofitCause` | [`DonationCampaignNonprofitCause2`](../../doc/models/donation-campaign-nonprofit-cause-2.md) | Required | The nonprofit cause that the campaign supports. |
| `online` | [`OnlineDonationSettingsResponse2 \| undefined`](../../doc/models/online-donation-settings-response-2.md) | Optional | The settings for online donations collected as part of the campaign. |
| `status` | [`DonationCampaignStatus2Enum`](../../doc/models/donation-campaign-status-2-enum.md) | Required | The current status of the donation campaign. |
