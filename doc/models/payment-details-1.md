
# Payment Details 1

The details of the payment. You must show your user these details before they confirm or cancel the payment.

*This model accepts additional fields of type unknown.*

## Structure

`PaymentDetails1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `amount` | [`Amount`](../../doc/models/amount.md) | Required | - |
| `counterparty` | [`Counterparty`](../../doc/models/counterparty.md) | Required | - |
| `description` | `string` | Required | The description for the payment. It is generated by the payment method, such as iDEAL, and should be shown to the user. |
| `expiresAt` | `string` | Required | The expiration date of the payment in ISO DateTime format, as described on ISO 20022 (YYYY-MM-DDThh:mm:ss.sss+/-hh:mm).<br><br>Example: **2025-12-30T14:15:30+01:00** |
| `additionalProperties` | `Record<string, unknown>` | Optional | - |
