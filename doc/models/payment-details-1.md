
# Payment Details 1

## Structure

`PaymentDetails1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `amount` | [`Amount110`](../../doc/models/amount-110.md) | Required | The amount of the payment. |
| `counterparty` | [`Counterparty11`](../../doc/models/counterparty-11.md) | Required | Contains information about the party that receives the payment funds. |
| `description` | `string` | Required | The description for the payment. It is generated by the payment method, such as iDEAL, and should be shown to the user. |
| `expiresAt` | `string` | Required | The expiration date of the payment in ISO DateTime format, as described on ISO 20022 (YYYY-MM-DDThh:mm:ss.sss+/-hh:mm).<br><br>Example: **2025-12-30T14:15:30+01:00** |

## Example

```ts
import { PaymentDetails1 } from 'adyen';

const paymentDetails1: PaymentDetails1 = {
  amount: {
    currency: 'EUR',
    value: BigInt(499),
  },
  counterparty: {
    accountHolder: {
      fullName: 'John Doe',
    },
    accountIdentification: {
      type: 'AccountIdentification1',
    },
  },
  description: 'Payment at MyShop. ref:12345678',
  expiresAt: '2025-12-30T14:15:30+01:00',
};
```
