
# Payment Details Response

*This model accepts additional fields of type unknown.*

## Structure

`PaymentDetailsResponse`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `details` | [`PaymentDetails`](../../doc/models/payment-details.md) | Required | - |
| `token` | `string` | Required | The token that identifies the payment. It is generated by Adyen and is needed to confirm or cancel the payment.<br><br>**Constraints**: *Minimum Length*: `1` |
| `additionalProperties` | `Record<string, unknown>` | Optional | - |
