
# Payment Details Response 1

## Structure

`PaymentDetailsResponse1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `details` | [`PaymentDetails11`](../../doc/models/payment-details-11.md) | Required | The details of the payment. You must show your user these details before they confirm or cancel the payment. |
| `token` | `string` | Required | The token that identifies the payment. It is generated by Adyen and is needed to confirm or cancel the payment.<br><br>**Constraints**: *Minimum Length*: `1` |

## Example

```ts
import { PaymentDetailsResponse1 } from 'adyen';

const paymentDetailsResponse1: PaymentDetailsResponse1 = {
  details: {
    amount: {
      currency: 'EUR',
      value: BigInt(499),
    },
    counterparty: {
      accountHolder: {
        fullName: 'John Doe',
      },
      accountIdentification: {
        type: 'AccountIdentification1',
      },
    },
    description: 'Payment at MyShop. ref:12345678',
    expiresAt: '2025-12-30T14:15:30+01:00',
  },
  token: 'ewoJIlNvbWVUb2tlbiIgOiAiU29tZUluZm8iCn0=',
};
```
