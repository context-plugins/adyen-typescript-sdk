
# Nonprofit

*This model accepts additional fields of type unknown.*

## Structure

`Nonprofit`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `causes` | [`NonprofitCause[]`](../../doc/models/nonprofit-cause.md) | Required | The causes that the nonprofit supports.<br><br>**Constraints**: *Minimum Items*: `1` |
| `description` | `string` | Required | The description of the nonprofit. |
| `goals` | `string[]` | Required | The goals of the nonprofit.<br><br>**Constraints**: *Minimum Items*: `1` |
| `id` | `string \| undefined` | Optional | The unique identifier of the nonprofit organization. This value is generated by Adyen. |
| `locales` | `string[]` | Required | The locales that the nonprofit supports, in [IETF BCP 47](https://en.wikipedia.org/wiki/IETF_language_tag) format.<br><br>**Constraints**: *Minimum Items*: `1` |
| `logoUrl` | `string` | Required | The URL to the logo of the nonprofit. |
| `name` | `string` | Required | The name of the nonprofit. |
| `regions` | `string[]` | Required | The regions where the nonprofit operates, in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format.<br><br>**Constraints**: *Minimum Items*: `1` |
| `termsAndConditionsUrl` | `string` | Required | The URL to the terms and conditions of the nonprofit. |
| `website` | `string` | Required | The URL to the website of the nonprofit. |
| `additionalProperties` | `Record<string, unknown>` | Optional | - |
