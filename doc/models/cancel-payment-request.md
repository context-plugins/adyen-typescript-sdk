
# Cancel Payment Request

## Structure

`CancelPaymentRequest`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `token` | `string` | Required | The payment token is an identifier for the payment. It is generated by Adyen on the response of the payment details.<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `1000` |

## Example

```ts
import { CancelPaymentRequest } from 'adyen';

const cancelPaymentRequest: CancelPaymentRequest = {
  token: 'ewoJIlNvbWVUb2tlbiIgOiAiU29tZUluZm8iCn0=',
};
```
