
# Secure Remote Commerce Checkout Data

## Structure

`SecureRemoteCommerceCheckoutData`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `checkoutPayload` | `string \| undefined` | Optional | The Secure Remote Commerce checkout payload to process the payment with.<br><br>**Constraints**: *Maximum Length*: `10000` |
| `correlationId` | `string \| undefined` | Optional | This is the unique identifier generated by SRC system to track and link SRC messages. Available within the present checkout session (e.g. received in an earlier API response during the present session).<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `40` |
| `cvc` | `string \| undefined` | Optional | The [card verification code](https://docs.adyen.com/get-started-with-adyen/payment-glossary/#card-security-code-cvc-cvv-cid).<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `20` |
| `digitalCardId` | `string \| undefined` | Optional | A unique identifier that represents the token associated with a card enrolled. Required for scheme 'mc'.<br><br>**Constraints**: *Maximum Length*: `80` |
| `scheme` | [`SchemeEnum \| undefined`](../../doc/models/scheme-enum.md) | Optional | The Secure Remote Commerce scheme. |
| `tokenReference` | `string \| undefined` | Optional | A unique identifier that represents the token associated with a card enrolled. Required for scheme 'visa'.<br><br>**Constraints**: *Maximum Length*: `80` |
